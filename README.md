## Using the projects

Start with the README inside the project you want to explore. Each project has its own inputs and instructions; some require the original course environment or external services. Shared course testing utilities are in `projects/.utils/`.

Run each project from its own `mpN` directory. A few original setup dependencies are worth checking:

- MP1 references `usd.json`, which was not included in its source submission folder. Its assignment instructions describe downloading the currency data.
- MP2 requires extracting `flask.zip` with the embedded `.git` directory intact for its Git-history analysis.
- Original links to course labs and Git workflows refer to files outside this projects-only collection; consult the [UW GitLab source repository](https://git.doit.wisc.edu/cdis/cs/courses/cs320/cs320-sp26-students/mxing7/labs-and-projects) for those materials.

Stored outputs and grading artifacts are preserved as submitted; the projects were not rerun during this import.
